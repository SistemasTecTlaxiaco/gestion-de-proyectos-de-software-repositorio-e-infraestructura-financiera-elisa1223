# Plataforma comunitaria para la preservación y transmisión de la lengua materna de Santa María Cuquila

## Proyecto

Repositorio correspondiente a la Práctica 2 de la Competencia 1 de Gestión de Proyectos de Software.

## Objetivo

Documentar una propuesta de financiamiento para el proyecto mediante la investigación de Stellar Community Fund (SCF) y Drips, relacionándolos con el backlog y las fases de desarrollo.

## Problemática seleccionada

**Preservación y transmisión de la lengua materna de Santa María Cuquila.**

## Estado del proyecto

El proyecto se encuentra actualmente en una **etapa de planificación, análisis y definición**, en la cual se están estableciendo los requerimientos, objetivos, alcances y posibles soluciones para atender las necesidades identificadas.

En esta fase se trabaja principalmente en la **documentación y organización del proyecto**, así como en la identificación de las principales brechas técnicas, operativas y de financiamiento que podrían afectar su desarrollo. Esto permite establecer una base clara para las siguientes etapas y definir de manera gradual las funcionalidades que deberán implementarse.

Por el momento, **no se afirma que exista financiamiento aprobado, una solución tecnológica completamente implementada ni una integración blockchain terminada**. La tecnología blockchain se considera una alternativa que puede evaluarse dentro de la solución cuando aporte beneficios concretos, principalmente relacionados con la **trazabilidad, transparencia y confiabilidad de determinados procesos o registros**.

Las necesidades y limitaciones relacionadas con el financiamiento, así como las brechas técnicas identificadas, se encuentran documentadas en **[FINANCIAMIENTO.md](FINANCIAMIENTO.md)**. Este documento permite dar seguimiento a las necesidades detectadas y sirve como referencia para definir posibles estrategias de financiamiento y desarrollo.

### Avance actual

* **Planificación:** definición inicial del proyecto, sus objetivos y alcance.
* **Análisis:** identificación de problemáticas, necesidades y oportunidades de mejora.
* **Documentación:** elaboración y organización de la información técnica y administrativa del proyecto.
* **Financiamiento:** identificación de necesidades y brechas que requieren atención antes de una implementación completa.
* **Tecnología:** evaluación de las tecnologías que pueden formar parte de la solución, considerando blockchain únicamente cuando sea técnicamente justificable.
* **Implementación:** aún no se considera terminada; las funcionalidades se encuentran sujetas a las decisiones y avances de las siguientes etapas.

El proyecto continuará avanzando de manera incremental, priorizando primero la definición de las necesidades y la viabilidad de la solución, para posteriormente establecer las funcionalidades, componentes tecnológicos y mecanismos de implementación correspondientes para la realizacion.
